# Space — Explore The Universe 🪐

تطبيق Flutter مبني على تصميم **Space** في Figma: مستكشف كواكب داكن بلمسة حمراء،
يعمل بالكامل دون إنترنت (كل الكواكب مرسومة برمجيًا بأسلوب ثلاثي الأبعاد).

## الشاشات

1. **Splash** — المريخ ضخمًا في أعلى الشاشة، عنوان "Explore The Universe" على ثلاثة
   أسطر، وزر أحمر دائري الحواف `Explore →`.
2. **Home (Planet Carousel)** — بانر علوي بقوس الكوكب، سؤال "Which planet would you
   like to explore?"، الكوكب الحالي كبيرًا في المنتصف، زرا تنقّل دائريان أحمران حول
   الاسم مع مؤشر صفحة (`4 / 9`)، صف مصغرات دائرية لكل الأجرام (المحدد بإطار أبيض)،
   وزر `Explore [Planet] →`.
3. **Planet Details** — زر رجوع أحمر دائري وعنوان في المنتصف، بطاقة وصفية
   ("Earth: The Blue Marble") مع قوس الكوكب خلفها، الكوكب كبيرًا، قسم About، سبع
   بطاقات إحصائية (المسافة، طول اليوم، الدوران المداري، نصف القطر، الكتلة،
   الجاذبية، مساحة السطح)، وزر `Next: … →` مثبت أسفل الشاشة.

## الأجرام

القمر + الكواكب الثمانية، ببيانات حقيقية (ناسا) ومظهر مرسوم لكل جرم:
تدرّج شعاعي بإضاءة علوية يسرى، أحزمة للعمالقة الغازية، قارات وسحب للأرض،
فوّهات للقمر وعطارد، وحلقة لزحل — كلها عبر `CustomPainter` واحد بدون أي صور.

## التشغيل

```bash
cd space_app_app
flutter create . --project-name space_app  # توليد مجلدات android/ios
flutter pub get
flutter run

flutter test   # اختبارات البيانات (9 أجرام، اكتمال الإحصائيات، زحل وحده ذو حلقة)
```

```
lib/

├── data/planets_data.dart          # القمر + 8 كواكب (بيانات حقيقية + مظهر مرسوم)
├── widgets/

│   └── primary_button.dart         # الزر الأحمر المشترك

    ├── home_screen.dart            # كاروسيل الكواكب + المصغرات

test/

```

## ملاحظات

- لا توجد حزم خارجية غير `cupertino_icons`؛ التطبيق يعمل دون اتصال بالإنترنت.
- خط **Poppins** مذكور في الثيم (`theme.dart`)؛ أضف ملفات الخط إلى
  `assets/fonts/` مع تعريف `fonts:` في `pubspec.yaml` لمطابقة أدفق، وإلا
  سيُستخدم خط النظام ويعمل التطبيق بشكل صحيح.
- المظهر مبني على لوحة تصميم Space في Figma (عُدّلت الألوان لتطابق قيمها).
